二次函数与抛物线

一、定义与一般式

形如 y = ax² + bx + c（a ≠ 0）的函数叫做二次函数，它的图像是抛物线。

关键系数

a 决定开口方向与开口大小；b、c 与 a 一起决定抛物线的位置。

二、抛物线的图像特征

  • 图像是一条抛物线，轴对称图形
  • 与 y 轴交于点 (0, c)
  • 与 x 轴交点个数由 Δ = b² − 4ac 决定
判别式

Δ > 0 两个交点；Δ = 0 一个交点；Δ < 0 无交点。

三、|a| 越大，开口越小

对比 x = 2 时三个函数的取值，值越大抛物线越陡、开口越窄：

  • y = 2x²，取值 8
  • y = x²，取值 4
  • y = 0.5x²，取值 2

四、顶点与对称轴

  • 顶点式：y = a(x − h)² + k，顶点为 (h, k)
  • 对称轴：直线 x = h
  • 由一般式求顶点：h = −b/(2a)，k = (4ac − b²)/(4a)

五、a 的符号对比

a > 0

  • 开口向上
  • 顶点是最低点
  • 函数有最小值 k

a < 0

  • 开口向下
  • 顶点是最高点
  • 函数有最大值 k

六、三种表达式

形式表达式适用场景
一般式y = ax² + bx + c已知三点坐标
顶点式y = a(x − h)² + k已知顶点与一点
交点式y = a(x − x₁)(x − x₂)已知与 x 轴交点

七、解题三步法

  • □ 辨析：确认是二次函数，别漏 a ≠ 0
  • □ 定型：按已知条件选合适的表达式
  • □ 求解：求顶点、对称轴与最值
易错点

对称轴漏写 x =；配方时符号出错；开口方向只看 c 不看 a。
