# spec/ — 机器可读的规范稳定资产

本目录是「1帧6秒」规范面向程序与 AI agent 的**稳定 URL 层**。文件内容以 `version` 字段标明规范版本(当前 v1.0);URL 一经发布不再变更,破坏性修订会递增版本号并保留旧版。

| 文件 | 内容 | 消费方 |
|---|---|---|
| `levels.json` | L1~L8 全部转码参数(唯一真相源):间隔/缩放/灰度/CRF/音频/tune/2-Pass 公式/预期体积 | `1f6s.sh`、在线转码服务、托管站复检、任何 agent |
| `scenarios.json` | 九大场景→推荐级别映射 + 三问选择器完整规则 | 托管站选择器、agent 选级 |
| `redlines.json` | 15 类禁用场景结构化清单 | 上传前预检、agent 判断适用性 |

## 与其他副本的关系

- `skill/1f6s-compress/levels.json`:1f6s.sh 的随包副本,内容与本目录一致;修改参数时两处同步更新,并在提交信息注明
- 下游项目(在线转码服务、托管站)拷贝使用时,请在升级时对照本目录的 `version` 字段

## CORS 说明

本站托管于 GitHub Pages,无法自定义 HTTP 响应头。浏览器端跨域读取本目录 JSON 需经代理;`curl`/服务端/agent 抓取不受影响(内容即全部)。
